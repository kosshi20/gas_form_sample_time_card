# Googleフォーム連携 タイムカード自動記帳システム
Googleフォームをタイムカード代わりとして利用し、送信された出退勤データを厚生労働省指定様式(サービス提供実績記録票)をベースとしたスプレッドシートへ自動反映する Google Apps Scriptです。


## 機能・特徴
- 環境変数(スクリプトプロパティ)の活用: 各種固有IDなどの秘匿情報・環境依存パラメータはスクリプトプロパティに格納し、コードの安全性を確保。

- マジックナンバーの排除: 設定情報はすべて`CONFIG.js`に集約し、高いメンテナンス性を実現。
  - ※公開されている`CONFIG.Sample.js`はサンプルのため、実際に使用する際はプロパティのキー名を環境に合わせて変更してください。
  
- 名前を選択することにより、移行、継続どちらにも入力することが可能。

- 実際の運用では休日は必要ありませんが、どの日付でも試せるように31日分のデータで作成済み。
